Manage mods on your Icarus dedicated server without touching an FTP client: browse the
community mod index, install mods in one click (EXMODZ data mods are converted
automatically), and keep your own game in sync.

## Downloads

| OS | File | How to run |
|---|---|---|
| Windows | `IcarusEasyModSetup-{{VERSION}}.exe` | Run the installer |
| Windows (portable) | `IcarusEasyMod-{{VERSION}}-windows-x64.zip` | Extract, run `IcarusEasyMod.exe` |
| Linux | `IcarusEasyMod-{{VERSION}}-linux-x64.tar.gz` | Extract, run `./run.sh` |
| macOS | `IcarusEasyMod-{{VERSION}}-macos-<arch>.tar.gz` | Extract, run the `IcarusEasyMod` binary |

The app opens in your browser automatically - keep the console window open while using it.
Verify your download against `SHA256SUMS.txt`.

> Windows SmartScreen may warn about an unknown publisher (builds are not code-signed):
> choose "More info" then "Run anyway".
